**Goal:** Replace the classification engine's chapter-17-only EAL dataset with the complete, real, official 20-chapter EAL/EWC catalogue, and add 17 new real origin/process options across 6 additional chapters (08, 13, 14, 15, 16, 20) that the user identified as relevant to their customer base.

## Global Constraints

- Every code, description, and hazard flag in `eal-koder-full.json` must come from the real, official source CSV — no invented codes, tonnages, or descriptions.
- Deprecated ("Utgått") entries are excluded via `Registrerbar !== "Ja"` — verified during design to map exactly 1:1 with "Utgått" status across all 1,126 real level-3 rows, zero mismatches.
- `assignEalCode`'s matching/ambiguity logic itself must not change — this plan only feeds it richer data.
- Two real "all-one-way" chapter quirks must be documented (code comment) and tested, not treated as bugs: chapters 1301–1308 and 1406 are entirely hazardous (no non-hazardous mirror codes exist in the real catalogue); chapter 2003 is entirely non-hazardous.
- No change to `Avfallstoffnummer.csv`-related code (avfallsstoffnummer/EAL crosswalk) — unrelated to this slice.

```python
"""
One-off build script: parses the real, official EAL/EWC code list (Norwegian) from
scripts/data-sources/EALKoder.csv into lib/data/eal-koder-full.json.

Source: exported from the user's EALKoder.numbers (Apple Numbers), itself a transcription of
the official Norwegian EAL/EWC catalogue (all 20 chapters). The CSV's header row is repeated
once per record block (an export quirk of the source file) — this script skips every
repeated header line, keeping only real data rows.

Deprecated ("Utgått") codes are excluded via the `Registrerbar` column (Nei == excluded) —
verified during design that Registrerbar=="Nei" maps exactly 1:1 with "Utgått" in the
description text, across all 1,126 level-3 rows, so this boolean is used as the (cleaner)
exclusion rule instead of string-matching descriptions.

Run: python3 scripts/build-eal-koder-full.py
"""

import csv
import json
from pathlib import Path

SOURCE_CSV = Path(__file__).parent / "data-sources" / "EALKoder.csv"
OUTPUT_JSON = Path(__file__).parent.parent / "lib" / "data" / "eal-koder-full.json"


def main() -> None:
    entries = []
    with open(SOURCE_CSV, encoding="utf-8-sig") as f:
        reader = csv.reader(f, delimiter=";")
        for row in reader:
            if not row or row[0] in ("", "Nivå"):
                continue  # skip blank lines and repeated header rows
            nivaa_str, kode, beskrivelse, registrerbar, farlig = row
            if registrerbar != "Ja":
                continue  # skip deprecated ("Utgått") entries
            entries.append(
                {
                    "nivaa": int(nivaa_str),
                    "kode": kode,
                    "beskrivelse": beskrivelse,
                    "farlig": farlig == "Ja",
                }
            )

    OUTPUT_JSON.write_text(
        json.dumps(entries, ensure_ascii=False, indent=2) + "\n", encoding="utf-8"
    )
    print(f"Wrote {len(entries)} entries to {OUTPUT_JSON}")


if __name__ == "__main__":
    main()
```

// mutating the base object — each request gets its own merged copy, so a custom entry
